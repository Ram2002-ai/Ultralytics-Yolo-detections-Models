# YOLOv8 Deployment Suite

A comprehensive computer vision application combining multiple YOLOv8 capabilities:
- Object Detection (80 COCO classes)
- Object Counting
- Segmentation
- Pose Estimation
- Customer Detection (person only)
- AI Workout Monitoring (Pushup, Squat, Pullup, etc.)
